# Error de generación: un ancla cuyo nombre lleva `\` produce una query que no matchea nada

Capturar la sección `#### El separador es \n` de [`concepts/capture.md`](../../subsystems/bilinker/concepts/capture.md) falla:

```
Error: la query generada no matchea ningún nodo en subsystems/bilinker/concepts/capture.md:
(section
  (atx_heading (inline) @n1 (#eq? @n1 "El separador es `\n`"))) @target)
```

El texto del heading entra crudo en el predicado. Adentro de una query de tree-sitter, `\n` es un salto de línea, así que el predicado busca un nombre que tiene un newline en el medio — y no existe.

## Las dos mitades del mismo predicado no coinciden

`rewrite_name_predicate` —la que **reescribe** el nombre al reanclar— sí escapa:

```rust
let escaped = new_name.replace('\\', "\\\\").replace('"', "\\\"");
```

`real_name_predicate` —la que lo **escribe la primera vez**— no escapa nada:

```rust
format!("\n  {field}: ({name_type}) {cap} (#eq? {cap} \"{name_text}\")")
```

Escribir y reescribir el mismo campo con reglas distintas es la forma del defecto, y no sólo su causa: el mismo nombre pasa a producir dos queries según por qué camino se generó.

**Y hay un caso peor que el que se ve.** Un `"` en el nombre cierra el string de la query: no da una query que no matchea, da una query **inválida**, y hoy la única defensa es que `rust_impl_predicate` descarta los nombres con comillas —`if text.contains('"') { continue; }`— que es un parche en uno solo de los cinco caminos.

## Qué hay que hacer

Un solo lugar que escape, usado por los dos lados. Hoy hay cinco funciones que arman el predicado —`real_name_predicate`, `rust_impl_predicate`, `markdown_section_predicate`, `markdown_table_row_predicate`, los dos de YAML— y cada una formatea el string a mano.

## Cuándo está hecha

- Capturar `#### El separador es \n` resuelve y verifica.
- Un ancla con `"` en el nombre produce una query válida que matchea.
- El escape es uno solo, y `rewrite_name_predicate` usa el mismo.
- Hay un test por cada carácter que hoy rompe: `\` y `"`.

## Lo que no entra

**Repuntar lo que ya está escrito.** Ningún capture existente lleva estos caracteres —si los llevara no habría resuelto nunca— así que no hay migración: el defecto impide crear, no corrompe lo creado.
