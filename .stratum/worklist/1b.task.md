# `integration/acreta.md` está mal escrito — es Accreta, con dos c

`subsystems/bilinker/integration/acreta.md` describe la integración con **Accreta**, y el nombre del archivo se comió una `c`.

## Qué hay que hacer

```
git mv subsystems/bilinker/integration/acreta.md \
       subsystems/bilinker/integration/accreta.md
```

Y revisar si el error se repite en otro lado: el título del archivo dice "Accreta" bien, así que es sólo el nombre — pero conviene un `grep -ri acreta` que descarte que haya más, distinguiendo los falsos positivos (`Accreta` contiene la subcadena).

## Es barato hoy y no siempre

**Ningún bilink lo apunta** —`bilinker get subsystems/bilinker/integration/acreta.md` no devuelve nada— y ningún markdown lo linkea. Así que renombrarlo es un `git mv` y nada más.

Con un bilink encima sería otra cosa: el capture guarda el path, así que el rename lo deja `MOVED` y hay que correr `bilinker apply` para repuntarlo y `accept` para aprobar la ubicación nueva. No es difícil, pero es un ciclo completo en vez de un comando — y conviene hacerlo antes de que alguien lo vincule.

Los otros dos archivos de esa carpeta —`impact.md`, `worklist.md`— están bien escritos.
