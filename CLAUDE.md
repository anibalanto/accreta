## Claude Code

Las tres guías que `AGENTS.md` nombra por path son **skills**, y se cargan en vez de leerse:

| Cuándo | Skill |
|---|---|
| saber qué sigue, mover o crear un ítem, planificar | `worklist` |
| cualquier tarea que toque bilinks — prerequisito del método | `bilinker` |
| componer cualquier comando con un path | `stratum-paths` |
